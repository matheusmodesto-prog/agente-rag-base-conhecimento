# Perguntas Frequentes — Empresa Exemplo

## A IA substitui completamente uma pessoa?

Não. O agente automatiza perguntas frequentes, consultas à base de conhecimento e triagens iniciais. Casos sensíveis, exceções e solicitações específicas podem ser encaminhados para uma pessoa.

## O sistema pode usar documentos da empresa?

Sim. Documentos autorizados podem ser processados e transformados em uma base de conhecimento consultável pelo agente.

## O agente pode inventar uma resposta quando não encontra a informação?

Não. Quando não houver contexto suficiente na base, a orientação é informar que a informação precisa ser confirmada por atendimento humano.

## É possível atualizar a base de conhecimento?

Sim. Novos documentos podem ser adicionados e os embeddings podem ser atualizados pelo fluxo de ingestão.

## O WhatsApp pode ser integrado?

Sim. O fluxo foi pensado para receber mensagens por webhook e pode ser conectado a provedores de API para WhatsApp, como a Z-API.
